Rules:

- No mockups, no hand-drawn layout, no dark-theme-only crops — these are evidence users judge before installing.
- Crop to the panel, no desktop chrome, no session titles or personal paths.
- Keep each file under ~300 KB (PNG, full width) so the README stays fast.
